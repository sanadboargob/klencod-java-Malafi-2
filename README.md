# ملفي (Malafi) — منبه ومهام ومواعيد عمل

تطبيق أندرويد عربي (RTL) بواجهة عصرية، مكتوب بـ Java **بدون أي مكتبات خارجية**.

## المميزات
- واجهة تعريفية (5 شاشات) عند أول تثبيت، مع سؤال عن اسمك وطلب إذن الإشعارات
- **المنبهات**: وقت، اسم، تكرار بأيام الأسبوع أو مرة واحدة، غفوة، نغمة مخصّصة، اهتزاز، رفع الصوت تدريجياً
- شاشة رنين تظهر فوق شاشة القفل، وتعمل حتى بعد إعادة تشغيل الهاتف
- **المهام اليومية**: تذكير في وقت المهمة، علامة إنجاز، حلقة تقدم، سلسلة أيام متتالية 🔥
- **مواعيد العمل**: أيام وساعة الدوام وتذكير قبله (0 / 5 / 10 / 15 / 30 / 60 دقيقة)
- الصفحة الرئيسية: تحية حسب الوقت، المنبه القادم بالعدّ التنازلي، مهام اليوم، فكرة اليوم
- وضع داكن وفاتح، شعار خاص برسم برمجي (ملف `logo.png` للمعاينة)

## البناء
**المتطلبات:** JDK 17، Android SDK 34، Gradle 8.9 (الـ wrapper مرفق).

1. **Android Studio**: File ← Open ← اختر مجلد المشروع ← Run.
2. **سطر الأوامر**: `./gradlew assembleDebug` ← الملف في `app/build/outputs/apk/debug/app-debug.apk`
3. **من الهاتف بلا حاسوب**: ارفع المشروع إلى مستودع GitHub، وسيبني ملف
   `.github/workflows/build.yml` ملف APK تلقائياً. نزّله من تبويب Actions ← Artifacts.

## هيكل الكود (`app/src/main/java/com/malafi/app`)
| الملف | الدور |
|---|---|
| `MainActivity` | الشاشات الخمس ونافذة الإضافة/التعديل |
| `OnboardingActivity` | الواجهة التعريفية |
| `AlarmActivity` / `AlarmService` | شاشة وصوت المنبه |
| `Scheduler` | جدولة المواعيد عبر AlarmManager |
| `Store`, `Item` | التخزين المحلي والنموذج |
| `Notifs`, `*Receiver` | الإشعارات وأزرارها وإعادة الجدولة بعد الإقلاع |
| `Ui`, `Theme`, `LogoView`, `ToggleView`, `ProgressRing` | مكونات الواجهة |

## ملاحظات
- أقل إصدار أندرويد: 8.0 (API 26).
- على بعض الأجهزة (شاومي، أوبو، سامسونج...) فعّل "التشغيل التلقائي" وأوقف توفير البطارية للتطبيق لضمان دقة التذكيرات.
